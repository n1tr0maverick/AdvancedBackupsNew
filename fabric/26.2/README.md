# Fabric - 26.2

This is the port for Fabric Minecraft 26.2 (Chaos Cubed, released June 16, 2026).

## Build Information
- **Version**: 3.8-26.2
- **Fabric Loader**: 0.19.3+
- **Fabric API**: 0.157.0+26.2
- **Java**: 25+

Toast background rendering is restored for 26.2 using `GuiGraphicsExtractor.blitSprite` and `RenderPipelines.GUI_TEXTURED`.

For full documentation, see the main repository README.
